## Qué ofrece

Este servidor MCP está diseñado para que los asistentes de código tengan **contexto técnico real** del proyecto y una **memoria operativa** que persiste entre sesiones.

	<Card title="Arranque en frío" icon="rocket">

	<Card title="Memoria inteligente" icon="pencil">

## Para quién es

**Ideal si:**
- Trabajas en proyectos medianos/grandes y necesitas recordar decisiones técnicas semanas después.
- Quieres que las convenciones y fixes importantes no se pierdan al final de cada sesión.
- Usas Claude Desktop/Code y quieres enriquecer su contexto con información real de tu codebase.
- Necesitas exponer contexto de proyecto vía HTTP a otras herramientas.

**No es para:**
- Resúmenes automáticos de sesión (eso ya lo hace SessionMemory).
- Búsqueda semántica general de código.
- Reemplazar completamente la memoria de tu asistente.

## Flujo recomendado de memoria

1. Durante el trabajo → `save-decision` cuando tomas decisiones importantes.
2. Al final de sesión compleja → `suggest-promotions` para descubrir qué vale la pena guardar.
3. Promueves lo importante → `promote-memory`.
4. Sesiones futuras → `get-context` y `search-memory` ya traen ese conocimiento.

## Transporte y compatibilidad

| Uso                        | Transporte     | Recomendado |
|---------------------------|----------------|-------------|
| Claude Desktop / Code     | stdio          | Sí          |
| Dashboard + API HTTP      | http o sse     | Sí          |
| Herramientas externas     | http           | Sí          |

Compatible con Go 1.26.2+ y MCP Specification 2025-11-25.
